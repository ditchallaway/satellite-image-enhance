# Safety Checklist

Before delivering edited listing photos, verify:

1. The room still looks like the same room.
2. Walls, floors, counters, cabinets, appliances, windows, fixtures, and doors did not change materially.
3. No fake renovation, staging, view, sunlight, or luxury finish was added.
4. Important defects were not hidden.
5. Straightening did not crop away important listing information.
6. Remove-only edits changed only the named target.
7. Batch outputs have consistent orientation, color, and presentation.
8. The user has reviewed or will review the files before public use.
